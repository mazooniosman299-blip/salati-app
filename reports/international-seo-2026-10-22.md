# تقرير صلاتي: International SEO — تغييرات محلية غير منشورة

تاريخ المراجعة: 22 أكتوبر 2026. المشروع: `/workspace/sites/salati-world`.
الموقع: https://salati-world-prayer.sprytitan65.chatgpt.site/
الإصدار المنشور السابق: Sites 103. لم تُنشأ نسخة Sites جديدة، ولم يحدث دفع Git أو نشر في هذه المهمة.

## نطاق الفحص

مراجعة مصدر HTML وJavaScript وCSS والبناء وService Worker والاختبارات، مع مراجعة وثائق Google الحالية. لا يمثل ذلك اختبارًا يدويًا لكل شاشة على هاتف حقيقي أو إثباتًا للفهرسة أو موافقة الإعلانات.

المسارات الموجودة فعليًا في dist:

| المسار | المحتوى | قرار SEO |
|---|---|---|
| `/` | تطبيق المواقيت والمصحف والقبلة والأذكار والإعدادات | صفحة رئيسية قابلة للفهرسة في المصدر |
| `/index.html` | نفس ملف الرئيسية | canonical إلى `/`؛ لا يضاف تكراره للخريطة |
| `/privacy.html` | سياسة الخصوصية بالعربية والإنجليزية والتواصل | canonical ذاتي، مدرج في الخريطة |
| `/google611146e9ceec162a.html` | إثبات Google الأصلي | محفوظ دون تعديل، ليس صفحة محتوى أو هدف SEO |
| `/sitemap.xml` و`/robots.txt` | ملفات الزحف | محفوظان؛ الخريطة تضم صفحتين فقط |
| `/app-ads.txt` | تعريف إعلانات التطبيق | يخص AdMob؛ لا يثبت تفعيل AdSense للموقع |
| `/downloads/salati-1.0.67.apk` | تطبيق أندرويد | ملف تنزيل، ليس صفحة مدينة أو لغة |

المصحف والقبلة والأذكار والإعدادات تبويبات JavaScript داخل نفس الصفحة، ولا تملك مسارات مستقلة. لم تُختلق روابط لها. لا توجد صفحات مدن أو دول مستقلة حاليًا. ملفات الصوت والخطوط وJSON والصور أصول وليست صفحات محتوى.

## التغييرات المنفذة محليًا

- عنوان عربي أوضح للرئيسية، ووصف يذكر المواقيت العالمية والموقع والقرآن والتلاوة والقبلة والأذكار.
- عنوان ووصف إنجليزيان يتغيران مع اختيار الإنجليزية باستخدام وحدة `seo-metadata.js`، دون تغيير تحديد الموقع أو الحساب أو التلاوة أو التنبيهات.
- عناوين Open Graph ووصف المشاركة ورابط الصفحة واسم الموقع ونوع website، مع بطاقة Twitter summary. لا توجد صورة مشاركة أو تقييمات أو بيانات مختلقة.
- بيانات JSON-LD من نوع WebSite، بالاسم والرابط الحقيقيين واللغتين. لا توجد SearchAction لأن الموقع لا يملك رابط بحث مستقلًا. هذه البيانات لا تضمن نتيجة بحث محسّنة.
- ملء عناصر الترجمة الفارغة بالنص العربي الأصلي داخل HTML قبل تشغيل JavaScript، بما فيها H1 والعناوين والأزرار. جميع سمات الترجمة الأصلية الـ98 محفوظة، بما فيها الإنجليزية. المحتوى الديناميكي كالمواقيت ما زال يحتاج JavaScript.
- إضافة وصف عربي/إنجليزي لسياسة الخصوصية وتحسين خطها بإضافة font-display:swap.
- عدم تغيير canonical أو sitemap أو robots أو إثبات Google، وعدم إضافة hreflang غير صحيح.

## اللغات وحدود الفهرسة

العربية والإنجليزية موجودتان وتعملان عبر زر اللغة على نفس الرابط، مع حفظ الاختيار محليًا وتبديل lang وdir. سياسة الخصوصية تضم نصين عربيًا وإنجليزيًا. نص القرآن عربي؛ تبديل لغة الواجهة ليس ترجمة لمعاني القرآن. أسماء المدن وطرق الحساب تظهر في مواضع بصيغة ثنائية اللغة، لذلك الواجهة الإنجليزية ليست توطينًا حصريًا لكل سلسلة نصية.

تحديث metadata عند الضغط على English يحسّن اتساق الواجهة، لكنه لا ينشئ صفحة إنجليزية مستقلة قابلة للاستهداف. لا يُتوقع أن يرى Google نسخة إنجليزية مستقلة اعتمادًا على localStorage. لا hreflang حاليًا، التزامًا بشرط وجود روابط ومحتوى مترجم فعليًا.

المرحلة التالية المقترحة: صفحة عربية مستقرة وصفحة إنجليزية مستقرة، بمحتوى مرئي مترجم قبل JavaScript، وروابط تبديل لغة قابلة للزحف، وcanonical ذاتي وhreflang متبادل بعد اختبارهما. يلزم ضبط مسارات الأصول والبناء وService Worker وبدء لغة الواجهة كي لا تُستبدل لغة الرابط باختيار قديم. لم تُنشأ هذه الصفحات في هذه المرحلة.

## فرص الزيارات وصفحات الدول والمدن

هذه اقتراحات وليست صفحات منشأة أو روابط مدرجة في الخريطة، ولا توجد أرقام بحث موثقة لقياس حجم الفرص:

1. صفحة مواقيت مدينة مثل مسقط أو القاهرة أو لندن: التاريخ المحلي والمنطقة الزمنية وطريقة الحساب ومذهب العصر والجدول اليومي والشهري، شرح الفروق مع تقويم المسجد والمصدر وتاريخ التحديث. لندن تتطلب توضيح التوقيت الصيفي والصيف عند تعذر بعض الحسابات.
2. صفحة دولة تجمع روابط مدن موجودة فعلًا وتشرح طريقة الحساب المحلية والاختلافات الإقليمية. لا تُنشأ صفحة دولة لمجرد تبديل اسمها في قالب.
3. دليل أصلي بالعربية والإنجليزية عن اختلاف مواقيت التطبيقات، طرق الحساب، توقيت العصر، الموقع الدقيق، ومواقيت المناطق القطبية.
4. دليل عملي للقبلة وأذونات الحساس والمعايرة، ودليل الأذان والعمل دون اتصال وأذونات أندرويد، مع الفصل بين قدرات المتصفح والتطبيق.

ابدأ بعدد محدود من المدن التي يمكن التحقق من بياناتها ومراجعتها. لا تولّد 230 صفحة آليًا اعتمادًا على وجود المدينة في القائمة. استخدم رابطًا ثابتًا للمدينة؛ لا تفهرس كل يوم أو إحداثية أو اختيار حساب كرابط منفصل. لا تعمم معايرة مسقط المؤرخة على بقية المدن أو الأيام. لا تنشئ صفحات منفصلة لكل قارئ أو آية دون قيمة تحريرية مستقلة. صفحات الدول والمدن لا تُدرج في sitemap إلا بعد إنشائها وفحص محتواها واستجابة HTTP الخاصة بها.

## الهاتف والأداء

من المصدر: viewport صحيح، تصميم متجاوب بعدة نقاط توقف، دعم RTL/LTR، تركيز لوحة مفاتيح وprefers-reduced-motion، أبعاد صريحة لصورة المسجد، حزمة JavaScript مؤجلة، تحميل صفحات المصحف بالتدريج بدل إدراج المصحف كاملًا عند البداية.

الأحجام المحلية التقريبية قبل التغيير الأخير الطفيف: JavaScript 269 KB (85 KB gzip محلي)، CSS 49 KB (10.5 KB gzip)، Cairo 600 KB، بيانات القرآن 1.53 MB، صورة المسجد WebP 59 KB. ضغط gzip المحلي تقدير وليس إثباتًا لضغط الاستضافة.

Service Worker يحمّل ضمن التثبيت أصولًا تشمل نص القرآن والخطوط. هذا مفيد للعمل دون اتصال لكنه يزيد نقل البيانات في الزيارة الأولى. لم يُغيّر سلوك التخزين أو التلاوة في هذه المهمة. فرص لاحقة: تحويل Cairo إلى WOFF2 مع حفظ العربية والتشكيل والترخيص، ودراسة تحميل أصول المصحف عند فتحه دون كسر العمل دون اتصال. ملف APK غير محمّل ضمن قائمة الأصول الأولية.

لم يُشغّل Lighthouse أو اختبار هاتف مرئي أو قياس LCP/INP/CLS، ولم تتوفر بيانات CrUX/Search Console؛ لذلك لا توجد درجة سرعة أو ادعاء بتحقيق Core Web Vitals. يلزم اختبار العرض على 320/360/390 بكسل باللغتين، اختيار المدينة، تبويبات المصحف والقبلة، وتشغيل الصوت على جهاز فعلي قبل الحكم النهائي على تجربة الهاتف.

## AdSense والنطاق

AdMob الخاص بتطبيق Android مستقل عن AdSense للموقع. وجود معرف AdMob وapp-ads.txt لا يعني قبول الموقع في AdSense. لا يوجد كود adsbygoogle للموقع في HTML الحالي، ولا أُضيف إعلان أو ملف ads.txt بمعرف غير مؤكد.

وثائق Google تسمح بإضافة نطاقات، ونطاقات فرعية على منصات موجودة في Public Suffix List، ومواقع شركاء AdSense. تمت قراءة القائمة الحالية من مستودع publicsuffix/list الرسمي: توجد قاعدة `chatgpt.site`، ولا توجد قاعدة `sprytitan65.chatgpt.site`. بناءً على هذه القاعدة، النطاق القابل للتسجيل هو `sprytitan65.chatgpt.site`، وعنوان الموقع `salati-world-prayer.sprytitan65.chatgpt.site` نطاق فرعي منه. هذه عقبة محتملة في الإضافة المستقلة، وليست إثباتًا لرفض الحساب. لم يُثبت أن Sites شريك AdSense أو أن الحساب يسمح بإضافة هذا المضيف. التوصية نطاق مخصص تملكه وتتحكم به، مع خطة canonical و301 وتحديث Search Console والخريطة عند الانتقال؛ لم يُغيّر النطاق هنا.

قبل طلب القبول: محتوى أصلي مفيد، تنقل واضح، سياسة خصوصية دقيقة، معلومات عن الموقع والتواصل، والتحكم بكود HTML. لا يوجد حد رسمي موحد لعدد المقالات أو زيارات مضمون للقبول في المصادر المراجعة؛ وجود صفحتين ليس رفضًا آليًا لكنه يحد من تنوع المحتوى القابل للتقييم.

لخدمة الإعلانات عالميًا يلزم تقييم موافقات الخصوصية، وبخاصة CMP معتمد ومتطلبات Google في المنطقة الاقتصادية الأوروبية والمملكة المتحدة وسويسرا. UMP في Android لا يغطي تلقائيًا موافقات الويب. سياسة الخصوصية الحالية تصف نسخة الموقع بلا SDK إعلانات أندرويد؛ يجب مراجعتها وإفصاحاتها عند إضافة إعلانات الويب لاحقًا.

لا يمكن التحقق حاليًا من: حالة حساب AdSense، العمر/الهوية/الدفع، ملكية النطاق الأب، قبول المضيف داخل الحساب، موافقة Google، حالة الفهرسة، حجم الزيارات أو الأرباح المتوقعة، أو استجابة الترويسات العامة. أدوات الوصول العام فشلت في المهمة السابقة بسبب قيود الوصول؛ لم يُفترض أنها أصبحت متاحة. لم يُقدّم الموقع للمراجعة.
