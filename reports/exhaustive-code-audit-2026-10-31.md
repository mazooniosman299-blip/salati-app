## 5) الاختبارات الآلية
يحتوي CI على أربع طبقات مستقلة:
1. `code`: `npm ci`، كل اختبارات `npm test`، اختبارات القرآن DOM وSEO الإضافية، `npm run build`، مقارنة المخرجات المجمعة، `npm audit --omit=dev --audit-level=moderate`، واختبارات Java المستقلة للأذان والقرآن.
2. `android-debug`: تركيب Android SDK 36 وتجميع تطبيق Android `:app:assembleDebug`.
3. `whole-tree`: تدقيق الملفات والبيانات وHTML/SVG/XML ومراجع الموارد وأرشيفات APK/ZIP/JAR.
4. `browser-ui`: تشغيل Chromium حقيقي لاختبار التصميم والفواصل والقوائم على سبعة عروض شاشة، ومفاتيح الأذان والتلاوة، والسور، وتبديل اللغة، والتنقل دون إنترنت.

## 6) مخاطر ليست محسومة بالفحوص البرمجية
- لا يوجد اختبار هنا على هاتف المستخدم مع الشاشة مطفأة ودخول Doze وتوفير الطاقة وتغيير «عدم الإزعاج»، لذلك **لا ضمان لتسليم كل أذان في الخلفية**.
- لم يُنتَج أو يُوقَّع ملف APK إصدار جديد بالشهادة الأصلية، ولم يُختبر تحديث APK فوق النسخة الموجودة.
- التحقق من روابط تلاوات الأطراف الخارجية وسياسات الخادم وظهور إعلانات فعلية لا يمكن ضمانه من فحوص مصدر داخلية فقط.
- نجاح الاختبارات لا يساوي مراجعة بشرية دلالية لكل سطر أو تغطية 100% لكل فرع وتفاعل. النطاق يغطي شجرة الملفات بنيوياً ومسارات المصدر الأساسية سلوكياً، مع بيئة CI فعلية.
