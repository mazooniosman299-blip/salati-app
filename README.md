# صلاتي Salati 1.0.105

المصدر الكامل لتطبيق Android والموقع، مع الحفاظ على سجل المستودع وشهادة التوقيع الأصلية. لا يتضمن مفاتيح التوقيع أو كلمات المرور.

أُلغيت تنبيهات اقتراب الصلاة وإعداداتها، وتُلغى منبّهاتها القديمة عند التحديث. عبارة الفجر المرفقة «الصلاة خير من النوم» تعمل مرة واحدة وفق الإعدادات والصوت والأذونات وعدم الإزعاج. بقيت تسجيلات القرآن والأذان ومشغّل المصحف وصورة المسجد والأيقونات المعتمدة. الواجهة زجاجية فحمية داكنة مع أزرار زرقاء واضحة #2563EB اعتمدها المستخدم بعد معاينة فعلية. النص أبيض بتباين5.17:1، وحالات الضغط والتعطيل والتفعيل مميزة في الصفحات الست والقوائم. الأيقونات الخطية البيضاء وتمييز الصلاة الزجاجي محفوظان. التاريخان أصغر وأبيض أسفل اسم المدينة.

لا يوجد إذن موثّق لإعادة توزيع ملف الفجر المرفق؛ أُدرج بتوجيه المستخدم بعد إبلاغه، ولا يُوصف بأنه مرخّص.

ملف التثبيت: `dist/downloads/salati-1.0.105.apk`، versionCode 106. تقرير الاختبارات والبصمات والقيود: `reports/release-1.0.105.json`.

## البناء والتحقق

```sh
npm ci
npm test
npm run build
python3 scripts/prepare-android.py
android/gradlew -p android :app:assembleRelease :app:lintRelease
```

يتطلب Android JDK21 وSDK36. التوقيع بواسطة `scripts/sign-android.py` يتطلب استعادة المفتاح الأصلي وكلمة المرور خارج المستودع؛ لا يولّد شهادة بديلة. تعليمات المصدر والبناء الإضافية في [docs/source-README.md](docs/source-README.md).

نجحت اختبارات JavaScript والواجهات واختبارات Java المضيفة والبناء والفحص والتوقيع وتطابق أصول APK. لم يُنفذ اختبار هاتف فعلي أو تثبيت تحديث فعلي أو تقييم استماع بشري. لا تعادل الاختبارات الآلية هذه الفحوص.
