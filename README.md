# صلاتي Salati 1.0.109

المصدر الكامل لتطبيق Android والموقع، مع الحفاظ على سجل المستودع وشهادة التوقيع الأصلية. لا يتضمن مفاتيح التوقيع أو كلمات المرور.

أُلغيت تنبيهات اقتراب الصلاة وإعداداتها، وتُلغى منبّهاتها القديمة عند التحديث. عبارة الفجر المرفقة «الصلاة خير من النوم» تعمل مرة واحدة وفق الإعدادات والصوت والأذونات وعدم الإزعاج. بقيت تسجيلات القرآن والأذان ومشغّل المصحف وصورة المسجد والأيقونات المعتمدة. التحديث البصري 31 أكتوبر: الأزرق محصور بزر تشغيل/إيقاف التلاوة وزر إيقافها؛ مفاتيح التفعيل والإعدادات وجميع الأزرار الأخرى فحمية؛ الحفظ والتطبيق والإلغاء والتعديل والموقع والقوائم والحقول والتنقل وبطاقة مشغّل المصحف بالزجاج الفحمي. زر التلاوة فقط أزرق غامق #153D7A، بينما تُستخدم الدرجات الأصلية #0B0E13 للخلفية و#040509 للبطاقات. غُطّيت مساحة المشهد بنفس المسجد الأصلي دون قناع شفافية، وأُصلحت علامة الاختيار وتباعد التذييل وأيقونتا المصحف على حامل والمسبحة بحبات، وتغميق تحديد الصلاة وتحديث مربع السورة وتصميم المشغّل. أُبقيت وظائف التشغيل والإيقاف؛ زر الإيقاف مخفي وقت الخمول فقط. دوائر44×44 وفاصل التذييل12px والتواريخ والمحاذاة وصورة المسجد والأصوات محفوظة. فحوص فعلية وصور مقارنة في reports/visual-corrections-1.0.109. التاريخان أصغر وأبيض أسفل اسم المدينة.

لا يوجد إذن موثّق لإعادة توزيع ملف الفجر المرفق؛ أُدرج بتوجيه المستخدم بعد إبلاغه، ولا يُوصف بأنه مرخّص.

ملف التثبيت: `dist/downloads/salati-1.0.109.apk`، versionCode 110. تقرير الاختبارات والبصمات والقيود: `reports/release-1.0.109.json`.

## البناء والتحقق

```sh
npm ci
npm test
npm run test:selection-menus
npm run test:reference-controls
npm run build
python3 scripts/prepare-android.py
android/gradlew -p android :app:assembleRelease :app:lintRelease
```

يتطلب Android JDK21 وSDK36. التوقيع بواسطة `scripts/sign-android.py` يتطلب استعادة المفتاح الأصلي وكلمة المرور خارج المستودع؛ لا يولّد شهادة بديلة. تعليمات المصدر والبناء الإضافية في [docs/source-README.md](docs/source-README.md).

نجحت اختبارات JavaScript والواجهات  والبناء والفحص والتوقيع وتطابق أصول APK. لم يُنفذ اختبار هاتف فعلي أو تثبيت تحديث فعلي أو تقييم استماع بشري. لا تعادل الاختبارات الآلية هذه الفحوص.

أصل النسخة: `456f66722ce13636be2c3175522f0a7a9b989291`، مع الحفاظ على سجل GitHub السابق. بيانات المزامنة في `docs/github-source.json`.

## مراجعة تباين ألوان المشروع — 31 أكتوبر 2026

حُفظت درجة الخلفية المأخوذة من مرجع المستخدم `#0B0E13` والبطاقات `#040509`، وأصبحت نصوص المساعدة والحالات المعطلة والأيقونات والمكان المحدد من المصحف والقبلة والمواقيت والأذكار والمسبحة والإعدادات والصفحات العامة أكثر وضوحاً، مع إزالة تلوين الحالات النشطة بالأزرق. الاستثناء الوحيد للأزرق هو زرا تشغيل/إيقاف التلاوة وإيقافها بالدرجة `#153D7A`. تدرجات ودجت Android أصبحت فحمية متناسقة.

أُضيف الاختبار `npm run test:contrast` لفحص تطابق النسخ المسماة من CSS مع نظائرها وعدم انخفاض تباين النصوص، وحُدثت توقعات الاختبارات المتعلقة بمفاتيح التفعيل. رُفع رقم مخبأ PWA إلى `salati-shell-v145` ليحلّ محل النسخة القديمة بعد نشر ملفات الموقع.
