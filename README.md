## الوظائف

مواقيت الصلاة بحسب الموقع وطريقة الحساب والمنطقة الزمنية، الأذان وخدمة تشغيله بالخلفية على أندرويد، تنبيه اقتراب الصلاة، عبارة الفجر، المصحف والتلاوات ومتابعة الآيات المتاحة، القبلة، الأذكار والمسبحة، وويدجت نهاري وليلي.

تعمل التنبيهات بتسجيلين بشريين حقيقيين مضمّنين؛ تنبيه الاقتراب حي على الصلاة مع اسم الصلاة في الإشعار، وعبارة الفجر كاملة. لا حاجة إلى تثبيت صوت عربي على الجهاز. الواجهة زجاجية محايدة وتستخدم Motion وPhosphor محليًا، وصور المسجد فوتوغرافية حقيقية. الأذان في الخلفية يعتمد على أذونات أندرويد والمنبّهات الدقيقة وقيود البطارية. عمل المتصفح دون اتصال يحتاج تحميل الموارد أولًا؛ تلاوات الإنترنت ليست محلية تلقائيًا.

## ملفات المشروع

- `android/`: Java والخدمات والإشعارات والويدجت وإعدادات Gradle.
- ملفات JavaScript في الجذر: الحساب والموقع والقرآن والصوت والتخزين والواجهة.
- `dist/`: HTML وCSS والحزمة المبنية وموارد المصحف والصوت والخطوط والمدن وملفات التنزيل العامة.
- `scripts/`: البناء والتحضير والتوقيع والاختبارات المساعدة.
- `tests/`: اختبارات JavaScript وJava وPython.
- `reports/release-1.0.99.json`: تحقق الإصدار والتوقيع ومحتويات الحزمة.
- `reports/review-1.0.99.md`: التغييرات وحدود التحقق.

## تشغيل وبناء الويب

تحتاج Node.js وnpm وPython 3.

```bash
npm ci
npm test
npm run build
python3 -m http.server 4173 --directory dist
```

## بناء أندرويد

تحتاج JDK 21 وAndroid SDK 36 وأدوات البناء 36.0.0. ثبّت متطلبات Android/Gradle المذكورة في [دليل أندرويد](android/README.md).

لنسخة اختبار Debug منفصلة عن توقيع الإصدار:

```bash
python3 scripts/prepare-android.py
cd android
./gradlew :app:assembleDebug
```

لا تستخدم نسخة Debug لتحديث النسخة المنشورة؛ بناء التحديثات يتطلب مفتاح Release الأصلي.

بناء Release والتوقيع يحتاجان مفتاح الإصدار الأصلي خارج المستودع، مع ضبط `SALATI_KEYSTORE` و`SALATI_PASSWORD_FILE`. لا تنشئ مفتاحًا بديلًا إذا أردت تحديث التطبيق المثبت. البصمة العامة المعتمدة في `android/signing-identity.json`، وأداة التوقيع في `scripts/sign-android.py`.
