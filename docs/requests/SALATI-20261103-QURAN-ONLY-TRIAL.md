# صلاتي: نسخة تجربة المصحف والمشغل فقط — 2026-11-03

> «وريني ليها في واجهتي انا»

## حدود التنفيذ
- تعديل صفحة `#mushaf` فقط: لوحة المصحف `#qSheet` والمشغل الحقيقي `#mushafPlayerSlot`.
- تظل الخلفية الأصلية `#0B0E13`، لوحة المشغل `#18191D`، وزر التشغيل الأصلي `#2563EB`.
- المشغل يحتفظ بعناصر الصوت الحقيقية `qTransport, qSeek, qStop`، إضافة إلى زر سابق/لاحق للسورة (عبر القائمة الأصلية) وزر التكرار المتصل بحالة `qRepeat`.
- نموذج الصفحة المصورة في المعاينة **صفحة واحدة فقط** عبر رابط خارجي، وليس ملف القرآن الموثوق الذي يمثل كل صفحة من 604؛ يعرض كدليل بصري فقط. الصورة لم تُعد رسمها، ولم يُغيّر أي حرف من `dist/quran/data.json`. تغيير السورة أو الضغط على «القراءة التفاعلية للآيات» يعيد واجهة القراءة الأصلية.
- حقوق استعمال المكتبة الكاملة للصور غير متحققة، ولم يُطلب الدمج أو نشر الموقع.
- APK من Gradle debug مع اسم مستقل `com.salati.prayer.preview`، لا يُحدّث التطبيق الرسمي `com.salati.prayer` وليس موقّعاً بالمفتاح الأصلي.
- لقطات الاختبار الحقيقية يجب أن تنتج من تشغيل ملفات هذا الفرع في Chromium؛ صورة التصميم المولّدة ليست دليلاً.

## مخرجات التحقق
- `npm ci && npm run build && npm test`
- `node tests/quran-source-integrity.cjs`
- `python3 tests/quran-visual-trial-browser.py`: عرض صلاتي الحقيقي/ألوانه/قابلية إرجاع المصحف للتصفح.
- `python3 scripts/prepare-android.py` ثم `cd android && bash gradlew :app:assembleDebug`.
- `aapt2 dump badging` و`apksigner verify` مع فحص تضمين صفحة الاختبار والمشغّل.
- رفع APK واللقطات كأدلة من GitHub Actions؛ نشر مسبق تجريبي منفصل، **لا تحديث للإنتاج**.
