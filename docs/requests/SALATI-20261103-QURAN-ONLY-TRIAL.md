# صلاتي — تصحيح تجربة المصحف الكامل والمشغّل فقط
2026-11-03

## طلب المستخدم الحاسم
> «مانفس التصميم المطلوب انت شكل المصحف دا بتجيبو صوره وليس كود كامل المصحف بكون كاامل ومعاه المشغل ابحث في الويب وحتفهم كلامث»

صور التطبيق الحقيقي من المستخدم: `102936.jpg`, `102937.jpg`. النسخة القديمة عرضت صورة من مصدر ويب للصفحة 591 فقط وأدت CSS المتعارضة إلى دفع زر التشغيل خارج لوحة المشغّل.

## ما نُفّذ
- حُذف عنصر الصورة `#qTrialPlate` والمصدر الخارجي `thequranworld.com` ومفتاح التبديل `#qTrialSwitch` نهائياً من `dist/index.html` و`dist/quran-visual-trial.js`.
- عاد `#qVerses` لعرض الصفحات التي ينتجها `QuranReader.makeReadingPage(index)` ديناميكياً من مصدر `dist/quran/data.json` الأصلي الذي يحتوي **604 صفحة / 6236 آية / 114 سورة**. كل آية في DOM تحمل `data-ayah` وقابلة للتفاعل؛ الآيات لم تتغير حرفياً.
- يستعمل القارئ الخط الأصلي المضمّن `MadinahHafsClassic.ttf` مع خط `AmiriQuran` كاحتياط، وإطاراً برمجياً أزرق حول الصفحة لا يعتمد على صورة ورقية واحدة.
- صُحّحت لوحة الصوت #18191D والزر #2563EB، وأُلغيت تعارضات grid/position الخاصة بالحالة `:has(#qStop:disabled)` التي ظهرت في لقطة الهاتف. ترتيب التحكم: إيقاف/سابق/تشغيل/لاحق/تكرار، جميعها أزرار حقيقية مرتبطة بأصل الصوت أو السورة والتكرار.
- بقيت بقية واجهة صلاتي الرسمية وبيانات القرآن ومحرك التلاوة كما كانت.
- أُضيف اختبار متصفح يقفز من الفاتحة إلى سورة الناس بالصفحة 604، ويرجع، ويتحقق من حدود الزر وتفاعلية أدوات التحكم واللون الأصلي.

## نتائج التحقق المطلوبة
- `npm ci && npm run build && npm test`.
- `node tests/quran-source-integrity.cjs` ونفس SHA256 الأصلي للبيانات.
- `python3 tests/quran-visual-trial-browser.py` والتقاط الصور الحقيقية.
- `python3 scripts/prepare-android.py` و`assembleDebug` و`aapt2` و`apksigner`.
- إصدار تجريبي منفصل جديد `salati-quran-full-code-trial-20261103`، لا يصدر على `production` أو Cloudflare.

## قيد تقني مهم
نسخة صلاتي الحالية توفر نص القرآن الحقيقي وترقيمه إلى 604 صفحة مع الخط العثماني الموجود في التطبيق؛ هذا ليس ادعاءً بالتطابق البصري الحرفي للأسطر الـ15 في طبعة مجمع الملك فهد QCF V2. للحصول على تطابق أسطر الطبعة يجب لاحقاً جمع بيانات مواضع الكلمات وخطوط الصفحات والتحقق من حقوق كل أصل. مرجع التنفيذ:
- https://api-docs.quran.com/docs/tutorials/fonts/font-rendering/
- https://api-docs.quran.com/docs/tutorials/fonts/page-layout/

لا صور مولّدة، ولا صورة صفحة واحدة، ولا ادعاء اختبار جهاز المستخدم أو توقيع APK بمفتاح الإصدار الرسمي.


## تأكيد جديد من المستخدم: تنفيذ ملء الشاشة والموجات (2026-11-03)
> «نفذ» بعد الوصف النهائي الموافق عليه في المحادثة.

التغييرات المقتصرة على مصحف صلاتي: شريط `qFullHeader` الحقيقي مع رجوع/سورة/جزء/خيارات/إظهار وإخفاء المشغّل؛ إخفاء ترويسة صلاتي وشريط تبويباته فقط أثناء فتح المصحف؛ `#qSheet` و`#qVerses` يملآن المساحة المتاحة مع تمرير نص القرآن الـ604 صفحة، لا صورة ورقية. نفس الخط المضمّن وأصول زخارف `quran-surah-ornament.svg` و`quran-ayah-rosette.svg` السابقة، مع كريم/بني استرشاداً بالصورة الأخيرة.

المشغّل يحتفظ بـ`qTransport` و`qSeek` و`qStop` ومعه أزرار السابق والتالي والتكرار الفعلية. شريط الموجة 63 عموداً متفاوت الارتفاع مع لون تشغيل أزرق حقيقي مرتبط بقيمة `qSeek`. **ارتفاع الأعمدة تمثيل بصري وليس تحليلاً صوتياً فعلياً للملف MP3**؛ هذا التمييز مقصود حتى لا ندّعي استنتاج البيانات الصوتية دون تحليل. لون المشغّل الأصلي `#18191D` والأزرق `#2563EB`.

اختبار `tests/quran-visual-trial-browser.py` يشمل القياس واللقطات بمقاسي 390×844 و430×932، تنقّل الفاتحة/الناس، قفل المشغّل وإظهاره دون حجب النص، استعادة التبويبات عبر الرجوع، التحقق من ارتفاع الأعمدة المتفاوت ومن أن التقدم يغير الأعمدة بالفعل.

معيار لا يدّعى دون دليل: مطابقة زخارف/سطور كل صفحة 100% لصورة المرجع الأصلي من مصحف مجمع الملك فهد، اختبار الصوت على جهاز مستخدم حقيقي، إعادة توقيع APK بالمفتاح الرسمي، أو النشر للإنتاج.
